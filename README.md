# vivaeventos-auth

Microservicio de autenticación y autorización para VivaEventos.

## Descripción

Encargado de:
- Login y registro de usuarios
- Gestión de roles (cliente, organizador, logística, admin)
- JWT tokens
- Políticas de acceso
